# ADR-002: Регистрация и вход только по email и паролю

## Статус
Принято

## Контекст
Продуктовый план зафиксировал: регистрация только по email и паролю, социальные провайдеры не подключаются, подтверждение email не требуется.

## Решение
- Email нормализуется на сервере, проверяется уникальность.
- Пароль хэшируется Argon2id, не хранится в открытом виде.
- Выдаётся короткоживущий access JWT (10–15 мин) и refresh token.
- Refresh token хранится на сервере в виде хэша с ротацией при обновлении.
- Восстановление пароля — по одноразовой ссылке с ограниченным сроком.

## Последствия
- Нет OAuth/социальной авторизации.
- Нет верификации email при регистрации.
