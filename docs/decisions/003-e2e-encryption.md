# ADR-003: E2E-шифрование для приватных разделов

## Статус
В процессе проектирования (блокировано)

## Контекст
Для «Гневного письма» и «Баночки воспоминаний» планируется сквозное шифрование. Сервер должен хранить только шифротекст и метаданные, не исходное содержимое.

## Решение (планируется)
Не разрабатывать собственные криптографические алгоритмы. Выбрать проверенную библиотеку/протокол и отдельно спроектировать управление ключами. Нужно решить восстановление доступа, несколько устройств, смену устройства, отзыв доступа и поведение после отвязки.

## Блокировка
До завершения проектирования E2E-протокола API воспоминаний возвращает HTTP 501, чат не имеет E2E, нельзя заявлять, что модуль защищён E2E.
